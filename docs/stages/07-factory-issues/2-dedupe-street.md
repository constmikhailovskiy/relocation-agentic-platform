**Тип:** баг · **Складність:** середня

Та сама квартира на OLX і ЛУН не склеюється в одну, якщо вулицю записано по-різному: «вул. Валова, 12» і
«вулиця Валова, 12», «просп. Свободи, 5» і «проспект Свободи 5». Працівник бачить дубль у видачі.

Відтворення: тест нижче зараз падає на `expect` (`'…|вулиця валова, 12|…'` замість `'…|вул. валова, 12|…'`).
Додай його в кінець `mcp/listings/test/dedupe.test.ts`, а в імпорт — `fingerprint`:
`import { dedupe, fingerprint } from "../src/dedupe.ts";`

```ts
it("«вулиця»/«вул.», «проспект»/«просп.» і кома після назви — та сама адреса", () => {
  const base = { district: "halytskyi", rooms: 2, areaM2: 54, floor: 3 } as const;
  const fp = (street: string) => fingerprint({ ...base, street } as Listing);
  expect(fp("вулиця Валова, 12")).toBe(fp("вул. Валова, 12"));
  expect(fp("проспект Свободи 5")).toBe(fp("просп. Свободи, 5"));
});
```

Причина — у `normalize` у `mcp/listings/src/dedupe.ts`: вона прибирає лише пробіли й регістр.
Виправ причину в нормалізації адреси. Тест не змінюй і не послаблюй; наявні тести дедупу мають лишитися зеленими.
